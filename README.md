# A-N-D-R-O-I-D-PF

Este repositorio contiene una serie de proyectos prácticos de Android Studio, desarrollados a lo largo de diferentes lecciones para aprender a utilizar y manejar componentes visuales básicos.

## Proyectos Incluidos

### 1. Proyecto002: Capturar el clic de un botón
- **Lección 1**: Introducción al manejo de eventos en Android.
- **Conceptos**: Uso básico de `Button`, `EditText` y `TextView`. Captura del evento de clic para realizar operaciones con los datos ingresados.

### 2. Proyecto003: Controles RadioGroup y RadioButton
- **Lección 2**: Trabajo con opciones excluyentes.
- **Conceptos**: Implementación de controles `RadioButton` agrupados dentro de un `RadioGroup` para permitir la selección de una única opción en operaciones matemáticas o toma de decisiones.

### 3. Proyecto004: Control CheckBox
- **Lección 3**: Trabajo con opciones múltiples.
- **Conceptos**: Uso de múltiples controles `CheckBox` para permitir al usuario seleccionar varias operaciones en simultáneo (ej. sumar y restar) y mostrar el resultado combinado en la interfaz gráfica.

## Tecnologías Utilizadas
- Android Studio
- Java / Android SDK
- Layouts XML (LinearLayout)
